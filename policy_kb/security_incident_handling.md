# Security Incident Handling Policy

Any ticket reporting a suspected data breach, unauthorized access, or encryption failure 
must be immediately escalated to the Security Response Team regardless of the original 
queue assignment. These tickets are automatically assigned Critical priority and bypass 
the standard SLA queue.

Customers reporting security incidents should avoid sharing sensitive credentials or 
personal data in the ticket body. The Security Response Team will initiate a secure 
communication channel within 1 hour of ticket receipt. All security incidents are logged, 
investigated, and reported in compliance with applicable data protection regulations.
